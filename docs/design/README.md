# 标志和配色

拾星助手用到的图形文件和配色。

## 标志

| 文件 | 说明 |
|---|---|
| `logo-gold-chip.svg` | 金色筹码标志：黑底圆盘、外圈「ASTRAL CHIP COMPASS」环字、金色圆环、中间一颗金色四角星。使用说明网页的页头用的就是这个图形。外圈的字用 Bahnschrift 字体（Windows 10 起自带），没有时退回 Segoe UI。程序图标（exe、窗口标题栏、系统托盘）也是这个图形，由 `advisor/ui/icon.py` 按尺寸画出（96 像素以下不写外圈的字，32 像素以下圆环和星星加粗放大），`packaging/app.ico` 是打包用的图标文件。 |
| `logo-gold-chip-small.svg` | 金色筹码标志的小尺寸版，32 像素以下用：不写外圈的字（小了只剩一圈杂点），圆环加粗、星星放大，16 像素也认得出。 |
| `png/logo-gold-chip-*.png` | 金色筹码标志各尺寸的位图（透明底，文件名里的数字是边长像素）：96 像素以下不写外圈的字，32 像素以下用小尺寸版。 |
| `png/logo-three-chips-*.png` | 另一版标志设计（三枚叠放的筹码，金色在上、蓝色在左下、紫色在右下，每枚是深灰外圈、稀有度颜色的色环和黑芯），程序里不用，留作对照。 |

金色筹码标志的颜色：圆盘 `#1d1f2b`，外圈的字 `#a9aec0`，圆环 `#f2b232`，星星 `#ffd36e`。
