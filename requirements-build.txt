# Nuitka 4.2 正式支持 Python 3.14。C 编译器用 PyPI 上的 ziglang（zig 自带 clang 和 Windows 的 C 运行库头文件），
# 装在虚拟环境里即可，不需要在系统里安装 Visual Studio 或 MinGW。

# 这里锁定的 ziglang 就是编真正的程序（Nuitka）和根目录启动程序用的那一版：build_release.py 的 build_env 把它放在
# PATH 最前，Nuitka 不再自己下最新版。换版本时一起改 advisor/version.py 的 THIRD_PARTY、THIRD_PARTY_NOTICES.md 和
# zig 的许可证说明（再运行 --licenses）：编译前的版本核对会查这几处。

ziglang==0.16.0
